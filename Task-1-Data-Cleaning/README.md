# Data Cleaning and Preprocessing

## Objective
To clean and prepare a raw dataset using Python and Pandas.

## Dataset
Medical Appointment No-Show Dataset from Kaggle.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

## Tasks Performed
- Checked missing values and duplicate records.
- Standardized column names and text values.
- Converted date columns into a consistent format.
- Checked and corrected data types.
- Identified and corrected invalid age values.
- Exported the cleaned dataset as a CSV file.

## Files Included
- `data_cleaning.py` – Python code for data cleaning.
- `KaggleV2-May-2016.csv` – Original dataset.
- `KaggleV2_May_2016_cleaned.csv` – Cleaned dataset.

## Result
The dataset was checked for data quality issues and standardized for further analysis.
